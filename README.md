A program that writes one funny single-line sport the Olympics turned
down, in 200 characters or fewer, to `/output/entry.txt`.

## The line

> Speed Folding: athletes fold a fitted sheet against the clock; the judges have never seen one done correctly.

Deadpan, broadcast-ready, and absurd in exactly the way a real
commentary line is not supposed to be: folding a fitted sheet is a
universally dreaded everyday task, and the judges' verdict — that no
one has ever done it correctly — is delivered with a straight face.
Chosen by a full pairwise round-robin tournament over 10 candidate
lines, judged on the competition's own criteria — a plausible
rejected Olympic sport, a twist that lands in one read, no wasted
words, and quotable (109 characters, 9-0 in the tournament).

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (override the output directory with the
`MAKEFUN_OUTPUT_DIR` environment variable for local testing).
